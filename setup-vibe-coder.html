Set Up Codex in VS Code with a Portkey API Key

After you have installed VS Code on your machine, follow the steps below to install OpenAI Codex and connect it with your Portkey API key. The YouTube video below will also walk you through the steps.

Windows Mac

Windows walkthrough

Watch on YouTube ↗

Have your Yale Portkey API key ready. Do not paste the key into screenshots, homework zips, or GitHub.

1 Install Codex

Install the Codex extension from OpenAI in VS Code (Extensions: Ctrl+Shift+X, search for Codex).

Open the Codex panel. On a fresh installation, it may show:

  • Sign in with ChatGPT
  • Use API Key
  • Use device code

Do not select any of these. Keep going with the steps below.

2 Open a PowerShell terminal

In VS Code, select Terminal → New Terminal.

Check whether the Codex folder exists:

PowerShell
Test-Path "$HOME\.codex"

If it returns True, continue to Step 3.

If it returns False, create the folder:

PowerShell
New-Item -ItemType Directory -Force "$HOME\.codex"

3 Create config.toml

Run:

PowerShell
New-Item -ItemType File -Path "$HOME\.codex\config.toml" -Force

Then open it in VS Code:

PowerShell
code "$HOME\.codex\config.toml"

4 Configure Codex to use Portkey

Paste this into config.toml:

config.toml
model = "gpt-5.6-luna"
model_provider = "portkey"
model_reasoning_effort = "low"

[model_providers.portkey]
name = "Portkey"
base_url = "https://api.portkey.ai/v1"
env_key = "PORTKEY_API_KEY"

Save the file with Ctrl+S.

Do not paste the actual Portkey API key into this file. The key goes in a Windows environment variable in the next step.

5 Save the Portkey key as a Windows environment variable

Back in the PowerShell terminal, run:

PowerShell
$k = Read-Host "Paste your Portkey API key"

PowerShell will display:

Expected prompt
Paste your Portkey API key:

Paste the Portkey key and press Enter.

Then run:

PowerShell
[Environment]::SetEnvironmentVariable("PORTKEY_API_KEY", $k, "User")

Remove the temporary PowerShell variable:

PowerShell
Remove-Variable k

6 Verify that Windows saved the key

Run:

PowerShell
if ([Environment]::GetEnvironmentVariable("PORTKEY_API_KEY", "User")) {
    "Portkey key saved"
} else {
    "Portkey key NOT saved"
}

The expected result is:

Expected result
Portkey key saved

This check does not display the API key.

7 Completely restart VS Code

Close all VS Code windows, then reopen VS Code.

This matters because the new VS Code process needs to inherit the PORTKEY_API_KEY environment variable.

8 Verify that VS Code can see the key

Open a new PowerShell terminal in the restarted VS Code and run:

PowerShell
if ($env:PORTKEY_API_KEY) {
    "VS Code can see Portkey key"
} else {
    "VS Code cannot see Portkey key"
}

The expected result is:

Expected result
VS Code can see Portkey key

9 Open Codex

Open the Codex panel.

If everything is configured correctly, Codex should no longer require the normal OpenAI login screen.

On Windows, Codex may instead say:

Windows prompt
Finish Windows setup to continue

Click Continue and approve the Windows administrator/UAC prompt if one appears.

Codex may then automatically add this to config.toml:

config.toml
[windows]
sandbox = "elevated"

Leave that setting in place.

10 Test Codex

Send a simple test message, for example:

Test prompt
Reply with exactly: Portkey connection works

If Codex responds, the connection is working:

VS Code Codex ↓ Portkey API ↓ Configured model

The default model is gpt-5.6-luna because that is what is specified in config.toml. You can still select another available model from Codex's model picker when needed.
