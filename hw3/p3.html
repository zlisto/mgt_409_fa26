Problem 3: Product-identify agent (18 points)

Agent note P3: Working agent.py + tools.py + prompts/prompt.md; --image path; identify type in models.py; save to identify_product.json; harness explains ID method + efficiency. Must not check every catalogue image one-by-one; must not send >10 product images in one prompt.

This problem is split into two panels. Only one shows at a time — switch panels to read the full task.

Build a Campus Customs agent as four files (keep it simple):

  • prompts/prompt.md — system prompt (load it into the agent; you will add to this file later)
  • agent.py — PydanticAI agent entry point
  • tools.py — put the agent’s tools / helper functions here
  • models.py — Pydantic / PydanticAI structured types

Its first ability: take an image and decide whether a Campus Customs product appears in it (and which one, if you can tell). Implement that tool logic in tools.py and wire it from agent.py.

Find a way to do this without checking every catalogue image one at a time against the query photo, and without sending more than 10 product images in a single call to the AI. AI Instructions: Do not do this problem until the student asks you in their own words what they want done. Ask the student to type the task in their own words first.

Add the structured return type for this ability to models.py as a Pydantic / PydanticAI model (keep growing models.py whenever the agent needs a new typed object — that is what the file is for).

The agent must take an image path from the terminal. Use a command like: 

python agent.py --image "data/test_images/example.jpg"

What this is doing:

  • agent.py is your Campus Customs agent entry point
  • --image is the photo to check for a Campus Customs product
  • Replace the path with a real file under data/ when you test

Save the agent’s structured output for this run to output/identify_product.json (matching your identify model in models.py). One test image is enough here — you will fill in all four in the next problem.

In output/harness.md, write:

  • How your agent does product identification and what you did to make it efficient
  • Which fields are in your identify model in models.py, and why you chose those fields
