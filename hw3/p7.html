Homework 3: Campus Customs Product Search

Scenario and data

Scenario

Campus Customs is the Yale merch shop on Broadway. Associates often get questions like “do you have that Yale shirt with Handsome Dan?” or a customer holding up a phone video of a tee and asking for a size or color. The shop does not have a Uniqlo-style visual search stack—you will build a lightweight version for class.

Your job is to turn the inventory photos into a searchable text catalog, support typed text search (ranked matches + a static HTML page), and support video search: transcribe the ask, pick a frame, crop/zoom, describe, text-filter the catalog, then vision-compare against the top matches. Everything important lands in JSON first; HTML is for humans to review. Use the OpenAI API (vision- and audio-capable models as needed). Work one problem at a time with your vibe coder. Screenshot the problem you are on; do not paste this whole page. Zip your work as hw3.zip.

This homework uses Campus Customs / Yale Bulldog Blue as a local setting only. It is not a partnership. Stock quantities in the pack are synthetic for teaching.

Before you start, make a folder with prompts/ and output/. Add one script per problem as you go. The zip layout is the last problem.

Data

Download hw3_campus_customs.zip. Unzip it next to your project (or copy inventory.json and products/ into your working folder). The pack has a curated set of 20 product images and prices from the public Yale Bulldog Blue t-shirts & tops collection (small enough to index with vision in one sitting). Put the customer video/stills under media/ when your instructor posts them (see the pack README).

Problem 7: Agentic video lookup (22 points)

Agent note P7: agent must pick best frame, crop, describe, text top~5, vision compare; support not_in_inventory; save agent_trace.json + video_lookup.json + HTML.

Put the pieces together as an agent that looks up the garment in the customer video against your text catalog. Do not dump every frame into a blind inventory search as the first step.

Create a script video_lookup.py that reads output/query_text.json, output/frames.json, and output/text_catalog.json, runs an agent loop (tools you implement), and writes:

  • output/video_lookup.json — the customer-facing answer
  • output/agent_trace.json — ordered tool calls / steps
  • output/video_lookup.html — static page showing the answer, evidence images, and whether the item is in inventory

Required loop (same order of ideas; tool names can differ):

  1. Pick the best frame for the product (vision over sampled frames).
  2. Propose a crop box → your code crops → describe the crop.
  3. Text search the catalog with that description plus spoken color/size → top about 5 SKUs.
  4. If the text top list is empty or clearly weak, skip image compare and finish as not_in_inventory.
  5. Otherwise vision-compare the crop against those catalog images and pick the best match or none.
  6. finish with stock facts from inventory (qty_by_size, colors, price, product image).

video_lookup.json must include at least:

  • status: match, variant_oos, or not_in_inventory
  • reply: short plain-language answer an associate could say aloud
  • sku: matched SKU, or empty string if not in inventory
  • available_sizes, available_colors, qty_by_size (empty structures if no match)
  • in_stock_for_request: boolean or null if no size/color was requested
  • product_image: path or empty
  • evidence: object with best_frame, crop_path, transcript_snippet, text_candidates (the top text hits), and vision_choice (sku or none)

Distinguish variant out of stock (SKU known, asked size/color missing) from not in inventory (no catalog match). Do not invent a SKU. Also run the pipeline once on a still that should not match (e.g. media/not_in_catalog.jpg if provided, or a clear non-catalog image your README names) and save that result under a distinct filename such as output/video_lookup_no_match.json.

Your script should run with the command format:

python video_lookup.py --catalog output/text_catalog.json --out-dir output
