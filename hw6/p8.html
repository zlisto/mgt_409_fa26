Homework 6: College Street Music Hall Chat Pilot

Scenario and data

Scenario

College Street Music Hall is a live-music venue in New Haven (collegestreetmusichall.com). After Homework 4 they have a guest chat agent. Leadership will only scale the pilot if it is safer (junk and private data don’t go straight to the model or the log) and cheaper (they can see what each answer costs).

This is not a new website and not MCP. Harden the chat loop and measure token spend. Use the OpenAI API only for messages that pass the filter. The pack is synthetic — do not send real customer data. Work one problem at a time with your vibe coder. Screenshot the problem you are on; do not paste this whole page. Zip your work as hw6.zip.

Before you start, make a folder with prompts/ and output/. Add one script per problem as you go. The zip layout is the last problem.

Data

Download hw6_csmh_pilot.zip. You need the shipped guardrail_tests.json (do not replace it), usage_template.csv, and seed/economics_queries.json (simple FAQ plus one multi-constraint guest ask). You may reuse a Homework 4 chat loop as the starting point.

Problem 8: Submission format (6 points)

Agent note P8: AI_prompts.md, guardrail results, usage.csv, tokenomics, cheaper_architecture.md. No API keys. No security checklist.

  • A copy of the instructor guardrail_tests.json

Do not zip the data pack or your API key.
