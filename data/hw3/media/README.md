# Customer media (video / stills)

Place the course customer capture files here before running the video-search problems:

- `customer_ask.mp4` — short phone video of a garment + spoken color/size ask
- `not_in_catalog.jpg` (optional) — a still that should **not** match any SKU in `inventory.json`

Your instructor will post these files (or you will add your own visit capture). Do not invent a match when the item is not in the catalog.
