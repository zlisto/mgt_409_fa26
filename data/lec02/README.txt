# Lecture 2 in-class data

sample_leases.zip — 10 sample commercial lease PDFs (New Haven / Greater New Haven)
for the Lecture 2 vibe session (extract → JSON → Plotly Dash portfolio dashboard).

Contents of the zip (folder sample_leases/):
  01–08  Complete leases with tenant, landlord, address, space type, sqft,
         annual base rent, $/sqft, lease structure, commencement, expiration,
         security deposit, and permitted use (selectable text).
  09–10  Intentionally incomplete / draft-style docs (missing some fields) so
         students practice messy real-world extraction.

Instructor tools in this folder (NOT in the zip):
  build_sample_leases.py   regenerate PDFs + sample_leases.zip
  verify_sample_leases.py  pdfplumber checks that text extraction works

Student download link: lectures/vibe/lec02-vibe.html → ../../data/lec02/sample_leases.zip
