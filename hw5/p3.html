Homework 5: Peabody MCP and Orchestrator

Scenario and data

Scenario

The Yale Peabody Museum (peabody.yale.edu) has visitor facts split across desks: hours and tickets, what’s on view, and house rules. Front-desk staff get questions that need more than one of those systems at once.

Your job is to wrap those systems as an MCP server for the museum, then build an orchestrator agent that uses those tools to finish complex visitor-ops tasks (and refuses when the tools disagree). This is not a React app (that was Homework 4). Use the OpenAI API for the agent. Work one problem at a time with your vibe coder. Type each problem in your own words. do not paste this whole page. Zip your work as hw5.zip.

This is a class project. The museum did not hire the class. Do not email or call the museum. Gallery names and public hours in the pack are inspired by the real site; program and policy JSON is course fiction.

Before you start, make a folder with prompts/ and output/. Add one script per problem as you go. The zip layout is the last problem.

Data

Download hw5_peabody_visitor_ops.zip. Read briefing/visitor_ops_memo.md. Call museum facts only through your MCP tools, not from memory of the live website.
