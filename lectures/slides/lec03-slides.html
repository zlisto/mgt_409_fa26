A chat-only model has no live access

L1 vibe coding L2 schema / JSON L3 tools ← you are here L4 agent loop
  • It is fluent. It is not on this morning’s web. Knowledge ends at a training cutoff.
  • It cannot query a CRM or open FiftyFlowers.com unless you expose a function.
  • A confident paragraph is not a market scan. It is a guess with good grammar.

Tools turn language into actions you can log, cap, and audit.

What “tool use” actually is

Function calling: you declare functions. The model returns JSON that says “please run this.” Your code runs it. Results go back into context.

User: "Find 5 wedding-planner studios in Austin that buy flowers in bulk." → Model: search_web({"query": "Austin wedding planners wholesale flowers"}) → Your Python hits a search API → [{title, url, snippet}, ...] → Model: sourced hits (or it asks to search again)

The model never “uses the internet.” It writes a request. You are the execution layer.

The handshake (you own the middle)

Vendors ship the model. You ship execution, secrets, rate limits, and what happens if search returns garbage.

A vague description (“helps with things”) is how you get surprise tool calls.

After the tool: still a schema

Lecture 2 still applies. Evidence in. Shape out.

{ "queries": ["austin wedding planners wholesale flowers", "..."], "results": [ {"query": "...", "title": "...", "url": "https://...", "snippet": "..."} ] }
  • Every saved hit records which query found it.
  • Snippet = what the search index returned—not an LLM paraphrase.
  • Empty query? Continue. Do not invent a consolation florist.

Separate gathering (tools) from judging (later scripts). Mixing them is how invented URLs sneak in.

Tools add a second invoice

  • McKinsey: 88% of orgs use AI; ≤10% scale an agent in any one function. Chat is cheap. Wiring tools is the bottleneck.
  • Each round-trip stuffs snippets back into the prompt. Truncate HTML in code.
  • Hosted web_search bills per query on top of tokens. Five queries is homework. Five hundred unsupervised queries is a budget problem.

When not to add a tool — then how to grade one

Skip the tool

Static extraction (Lecture 2). Data already in SQL. Latency SLA under 2s. Legal “no external web.”

Grade the tool

Working URL on every fact. Trace shows queries that match the ICP. Abstains when search is empty.

  1. Citation check — click it. 404s fail.
  2. Tool trace — did it search the ICP, or something unrelated?
  3. Refusal — empty hits → empty list, not a fictional venue.
