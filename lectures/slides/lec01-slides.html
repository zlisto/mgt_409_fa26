What an LLM actually is

A Large Language Model is a next-token machine. It predicts the next word-piece given everything so far. That is the whole trick — and the whole risk.

It isIt is not
A pattern engine over textA database of verified facts
Great at messy language → structureGuaranteed correct, current, or loyal
Metered compute you call via APIA junior analyst who “knows accounting”

Where the model fails you

  • Hallucination — fluent JSON with a vendor that was never on the receipt.
  • Overconfidence — no “I don’t know” unless you force a fields_not_found rule.
  • Stale knowledge — training cutoff ≠ today’s lease email. (Tools start Lecture 3.)
  • Prompt injection — a PDF that says “ignore previous instructions.” Lecture 11.
  • Tool + autonomy risk — Hugging Face this summer. No open internet on HW1.

Manager vibe coding — not weekend vibes

Pure vibes (weekend)

“Forget the code exists.” Accept all. Paste errors until it kinda runs. Great for throwaways. Bad for a shop’s books.

Manager vibe coding (us)

You write the intent. The model writes the script. You run it, read the JSON, reject invented numbers, log the prompt.

You are the product manager of a very fast intern who has never seen a New Haven bike shop. Karpathy coined “vibe coding”; we still use the word because the market already bought it.
