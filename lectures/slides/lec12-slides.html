Tokens are the unit you buy

  • Input — system prompt, history, retrieved docs, tool dumps. Output — the reply (usually 6× per token).
  • Guest message → prompt pile → Luna / Terra / Sol → response.usage × list price → append usage.csv.
  • Rule of thumb: ~1 token ≈ ¾ of an English word. Images and tool JSON still count.

If it is not in usage.csv, you cannot defend it. Homework 6 graders check the CSV against the brief.

Prompt cache: reuse the prefix

OpenAI name: prompt caching. If the API sees a long, identical prefix (system, tools JSON, static FAQ), those input tokens bill at a cached rate instead of full input. Output is never cached.

  • GPT-5.6: min prefix 1,024 tokens. TTL 30 minutes (prompt_cache_options.ttl = 30m). Exact prefix match.
  • Short-context: Luna cached $0.02 / write $0.25; Terra $0.20 / $2.50; Sol $0.50 / $6.25 per 1M.

Stable first — cache hits

System, tool schemas, static policy/FAQ. Same prompt_cache_key. Don’t reshuffle tools. Don’t put a UUID or timestamp at the top.

Changing last — or you bust it

User turn, churny RAG, clocks. Multi-agent: share one frozen tool/policy prefix. Unique shuffled prompts = unique full bills.

First call pays the write. Reuse is the discount. HW6 P7: propose a frozen prefix — you do not have to build it.
