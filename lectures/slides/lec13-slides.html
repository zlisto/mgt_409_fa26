Open Weight Models

  • Open weights: download the model and run it on your own computer. No per-token bill, and your data stays home
  • The gap is months: the best open models trail the best closed ones by ~4 months (Epoch AI)
  • China leads: DeepSeek, Qwen, Kimi, and GLM are the top open models
  • US: OpenAI released gpt-oss and Google has Gemma. Meta used to release open Llama models, but its newest flagship is closed

What It Takes To Run Them

  • Memory ≈ parameters × bytes each: 2 bytes at 16-bit (full precision), 1 at 8-bit, ½ at 4-bit
  • (active) = parameters used per word. Fast, but you still load all of them
  • One NVIDIA B200 GPU has 192 GB of memory, so an 865 GB model needs 5+ of them
  • Click a model to download it from Hugging Face

The Tech To Build Them

Three.js · free

3D in the browser with JavaScript. Yale SOM Virtual is built with it. Share a link and anyone can play.

Blender · free

Model, texture, and animate 3D assets. With Blender MCP, your vibe coder builds the scene for you.

Unreal Engine · free to start

Film-quality games and walkable worlds (Fortnite runs on it). Royalties only after $1M in revenue.

Godot · free, open source

Lightweight game engine for 2D and 3D. We use it in MGT 575 to have agents build games.
