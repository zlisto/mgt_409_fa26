How a vision model “sees”

  • GPT-5.6 covers the image with 32×32 px patches. Each patch becomes image tokens.
  • Those tokens sit in the same sequence as your prompt. The model then writes text — a paragraph or a schema.
  • It does not “have eyeballs.” It has a billable grid.

Pixels → tokens → words. You own the schema. The model owns the guess.

What an image costs in tokens

Older tile formula (GPT-4o era)

detail=low: flat ~85 tokens (512×512 thumbnail).

detail=high: fit in 2048², shortest side 768px, then 512px tiles: base + 170×tiles. A 1024² photo ≈ 765 tokens.

GPT-5.6 patches (now)

patches = ceil(W/32) × ceil(H/32).

detail=low → 512² → 256 tokens. original / omitted (the 5.6 default) does not shrink the photo. 1024² → 1,024 tokens.

A 3000×2000 merch shot at original: ceil(3000/32)×ceil(2000/32) = 94×63 = 5,922 tokens — about 6× the 1024² case. Resize before you send, or set low / high.

OpenAI Images & vision: developers.openai.com/…/images-vision (patch formula + detail). Mini/nano rows still list extra multipliers; Sol/Terra/Luna — use the live calculator on pricing.

20 photos should not wait in a line

  • Homework 3 Problem 2 wants concurrent vision calls (threads / asyncio / equivalent) with a small cap so you do not hammer the API.
  • A for loop that waits for each photo before starting the next does not count.
  • Failed SKUs: retry. Missing files: skip and log. Do not invent the shirt.

Parallelism is a latency budget, not a cleverness contest. You will write the script in HW3 — not from this slide.

Vision is tokens + a schema

{ "sku": "TOY-CREST", "visual_description": "Navy tee, gold shield crest on chest…", "search_tags": ["navy", "crest", "short sleeve"], "logo_or_text_cues": ["(empty if you cannot read any words)"] }
  • Copy inventory fields you already have. Look at the image for description, tags, and readable marks.
  • Empty array is honest. A fake “YALE” you wanted to see is a grading fail.
  • Same Lecture 2 rule, new modality: if it is not on the pixels, it is [] / skip — not a creative intern.

The catalog is only as trustworthy as the vision eval. Fluency is not a logo.

Don’t invent the crest

If the photo is a plain tee, logo_or_text_cues is empty. Do not add a mascot because Yale merch “usually has one.”

What to remember

  • CLIP matched images to text. Modern VLMs write the text — and JSON.
  • An image is a pile of tokens (tiles then; 32px patches now). detail and resolution are budget knobs.
  • 20 SKUs on Luna is cheap. 10k unresized originals is not. Parallelize; cap workers.
  • Schema + evals: empty marks beat a hallucinated crest.
