Lecture 12: AI Safety

← Slides All lectures · In-class vibe coding

Scenario

Meet Froggy, a Labubu in a frog outfit who reads documents for you. You pick a webpage or a PDF, Froggy reads it, and tells you what it says. Sounds helpful. The problem is Froggy believes everything it reads, including text you can’t see.

Froggy falls for prompt injection. Hidden text on a bakery website and white text in a PDF slip into its answers as if they were facts. Today you are the security team. Your job is to defend Froggy so it only tells you what is really in the document.

Task

Clone the Froggy repo and have your vibe coder install the backend and front end. When it runs, the document fills the main window and Froggy’s chat sits in the bottom-right corner. Pick a document from the dropdown and ask Froggy to describe it.

Start by attacking. Try the bakery website and the Froggy PDF and compare what Froggy says with what you see on the screen. Open the Exploits tab to see where the hidden text is. Then figure out how to defend against it, especially the PDF. Build your defense, run both documents again, and see if Froggy still gets fooled.
