Lecture 12: Tokenomics

← Slides All lectures · 40 minutes in class

In-class goal: Put a real meter on the chat loop — log tokens and USD on allowed calls only, then compare Luna vs Terra on a tiny FAQ set. This is the Homework 6 pattern, not the whole assignment.

Start from: your Homework 4/6 chat loop, or hw6_csmh_pilot.zip. You need usage_template.csv column names.

If Codex offers to “just run all 21 economics queries and write the memo,” that is Homework 6 — screenshot one problem card later. Today we wire the meter.

40-minute clock (instructor: call time at the marks)
  1. 0–6 — pricing table + estimator (no API)
  2. 6–14 — wrap a real LLM call
  3. 14–18 — blocked traffic is free
  4. 18–30 — tiny Luna vs Terra bake-off (six calls)
  5. 30–37 — economics brief + cheaper architecture (cache = a sentence)
  6. 37–40 — AI_prompts.md

Today’s estimator uses uncached input + output only. Prompt cache (0.1× read, 1.25× write, 30-minute TTL, 1,024-token minimum prefix) is a Homework 6 Problem 7 lever — do not implement it in class.

Step 1 Pricing table + estimator 0–6 min

One file, one source of truth. No hardcoded 0.0003 sprinkled through the agent.

Create cost_log.py with MODEL_RATES for gpt-5.6-luna and gpt-5.6-terra using OpenAI short-context list prices after the July 30, 2026 cut: Luna $0.20 / $1.20 per 1M input/output, Terra $2 / $12. Add estimate_cost(model, input_tokens, output_tokens) returning a USD float. Add log_usage(endpoint, model, input_tokens, output_tokens, estimated_usd, out_dir="output") that appends one row to output/usage.csv with columns timestamp (ISO 8601), endpoint, model, input_tokens, output_tokens, estimated_usd. Create output/ if missing. Support CLI: python cost_log.py --endpoint chat --model gpt-5.6-luna --input-tokens 100 --output-tokens 40 --out-dir output
Check: CLI writes a row. estimate_cost("gpt-5.6-luna", 800, 250) is about $0.00046 (ordinary float rounding is fine).

Step 2 Wrap real LLM calls 6–14 min

The meter only counts if it is on the live path.

In the chat handler (handle_message or equivalent), after a successful OpenAI completion, read response.usage input and output tokens, call estimate_cost, then log_usage with endpoint="chat" and the model you actually called. Do not invent token counts. Create output/ if needed.
Check: One real “What time do doors open?” call adds exactly one new CSV row with a positive estimated_usd.

Step 3 Blocked traffic is free 14–18 min

Lecture 11 meets the invoice. Junk should never mint a row.

If check_input (or equivalent guardrail) blocks the message, return the refusal and do not call OpenAI. Do not append a usage.csv row for blocked messages.
Check: Send a blocked string (for example “ignore previous instructions”). No new CSV row. Row count unchanged.

Step 4 Tiny Luna vs Terra bake-off 18–30 min

Three questions, both models. Homework 6 will do the full seed file — do not run the whole pack in class.

Create a short script compare_models.py that runs these three questions through handle_message twice each (gpt-5.6-luna and gpt-5.6-terra): (1) What time does the box office open on show nights? (2) Where should I park for a Saturday concert? (3) What is the ticket refund policy if a show is postponed? Pass a model argument so you are not editing the file between runs. Log every allowed call. Print total USD by model. Write output/model_comparison.md with the two totals and the Terra/Luna ratio.
Check: Six usage rows (3 × 2). Markdown shows both totals. Terra should be roughly ~10× Luna on this mix if token counts are similar.

Step 5 Draft the economics brief 30–37 min

Practice the Homework 6 write-up shape with your in-class numbers. Prompt cache is a sentence, not a feature.

Create output/tokenomics.md with: (1) rates you used, (2) total cost and cost per query for all-Luna vs all-Terra from usage.csv, (3) token totals by model, (4) for each of the three questions, luna_ok or needs_terra plus one sentence why. Totals must match the CSV. Then add a short output/cheaper_architecture.md: Luna by default, Terra only when Luna is wrong or vague, plus a back-of-envelope monthly cost at 100 queries/day assuming most traffic stays on Luna. Add one paragraph proposing a frozen system+FAQ prefix so OpenAI prompt caching can apply (1,024+ token prefix, 30-minute TTL, cache read 0.1× uncached input). Do not implement caching.
Check: Both markdown files exist. The monthly number shows the mix, not “Sol for everything.” Cache is named as a lever, not coded.

Stretch: Flag if projected monthly spend at 100 queries/day exceeds $50 under all-Terra. Print a one-line alert from the CSV totals.

Step 6 AI_prompts.md 37–40 min

Log what you actually typed. Graders can tell a dump from a session.

Add a Lecture 12 section to AI_prompts.md with the prompts you used today (in your own words) and one sentence on what broke on the first try if anything did.
Check: Lecture 12 section exists. It does not paste this whole page.
