Step 1 Skeleton — secrets never travel min 4–12

Homework 1 will grow prompts/ and output/. Start those habits now, on a throwaway lecture folder.

Create a folder lec01/ for MGT 409 Lecture 1 with:
- hello_llm.py
- requirements.txt listing openai and python-dotenv
- .env.example with OPENAI_API_KEY=your_key_here
- .gitignore that ignores .env, .venv, and __pycache__
- prompts/ (empty for now)
- output/ (empty for now)
- README.md with venv, pip install, copy .env.example to .env, and python hello_llm.py
Do not put a real API key in any file.
Check (by 12): .gitignore lists .env. No key in anything you would zip or commit.

Step 2 Install like a grown-up min 12–18

Run these in the terminal yourself. Do not paste your key into the vibe coder chat.

Update README.md with exact Windows and Mac commands:
python -m venv .venv
how to activate the venv
pip install -r requirements.txt
copy .env.example to .env (copy on Windows, cp on Mac)
Then remind me to paste the OpenAI key into .env locally only.
Check (by 18): pip list shows openai and python-dotenv. .env exists on disk and is ignored by git.

Step 3 First call — prove the API works min 18–28

One function. One model. One sentence. This is the whole course in miniature. Use a cheap model — not the flagship Sol until a cheaper model fails the eval.

In hello_llm.py:
1. Load OPENAI_API_KEY from .env with python-dotenv.
2. Define ask_llm(prompt: str) -> str that calls OpenAI chat completions.
3. Under if __name__ == "__main__": print ask_llm("In one sentence, what should a manager check after a vibe coder writes a script?")
4. If the key is missing, raise a clear error that says to copy .env.example to .env.
5. Print response.usage so I can see input and output tokens.
Check (by 28): python hello_llm.py prints one sentence and a token count. No traceback. If you are still debugging, stay here — JSON can wait.

If you finish early: Compute a rough USD cost from today’s OpenAI pricing using the usage object. Lecture slides used Luna at $0.20 / $1.20 per 1M tokens.

Step 4 JSON teaser (Homework 1’s heartbeat) min 28–36

Homework 1 does not want a paragraph about the bike shop. It wants rows. Practice on this fake register tape — not the HW1 zip.

Add extract_receipt(text: str) -> dict that:
- Calls the same model with response_format json_object (or equivalent structured output)
- Uses a prompt file prompts/demo_receipt.md (not a giant string only in Python)
- Schema keys: vendor, date, amount_usd, category, fields_not_found
- Rules in the prompt: never invent amounts; put missing keys in fields_not_found
- Input text:
"""
SPOKE N SNACK
New Haven CT
Jan 8 2026
Inner tubes x2    18.00
Tax                1.17
TOTAL             19.17
Paid VISA
"""
Print the dict. Write it to output/demo_receipt.json.
Check (by 36): File exists; JSON parses; amount_usd is 19.17 or the model honestly listed what it could not read. If it invents a vendor like “Nike,” fix the prompt, not the number by hand.
Do not: unzip Homework 1 and solve Problem 2 in this lab. Today is the pattern. Next lecture is a real PDF.

When it breaks — and it will — give the model the error and the one file. That is the same move you will use when read_receipts.py explodes at 1 a.m. Use this instead of skipping ahead.

I ran python hello_llm.py and got this error:
[paste traceback]
Here is hello_llm.py:
[paste that file only]
Explain the cause in plain English and suggest the smallest fix. Do not rewrite the whole project.
Check: You can say the cause out loud (missing key, wrong model name, venv not active, JSON parse fail).
