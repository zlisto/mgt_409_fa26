Lecture 4: Agents

← Slides All lectures · In-class vibe coding

The Scenario

Upgrade last lecture’s stock chatbot into a financial analyst agent. It loads a portfolio from a JSON file, chats about risk and replacements, and can act — compute metrics, swap a holding within a fixed universe, and dig into a name with price, news, and analyst coverage. Answers must come from tools and live data, not memory.

The Task

1. Keep (or refresh) your semester AGENTS.md: model, API keys, black-and-pink UI, Dash run rules (no auto-reloader / kill the whole process). Add agent house rules: max steps, never invent prices, only trade within the allowed universe, and always log every thought and tool call.

2. Reuse your chatbot skill for the Dash chat UI. Extend it (or add an agent skill) so the UI shows: chat history memory, the model’s thinking in a lighter font before the final answer, and a clear trail when a tool runs.

3. Build a portfolio analyst agent (PydanticAI or your own loop) with a strong system prompt. Load portfolio.json. Put this fixed replacement universe in the prompt (top large-cap names — keep it simple): AAPL, MSFT, NVDA, GOOGL, AMZN, META, AVGO, TSLA, BRK-B, JPM.

4. Wire tools the agent can call:

  • Portfolio metrics — one-year mean return, volatility, Sharpe, max drawdown
  • Replace a holding — swap one ticker for another only from the universe above; update the portfolio file
  • Analyze a stock — live price (Yahoo Finance), recent news (web search), and analyst-report style summaries (web search / filings snippets)
  • Portfolio optimization — suggest weights or a swap that improves risk/return under simple constraints

5. Harness checklist in the build:

  • Tools — the list above (hands)
  • Memory — chat history + current portfolio state
  • Goals — clear finish / max-step satiation so it cannot loop forever
  • Guardrails — universe allow-list; no inventing prices; refuse unsafe asks
  • Audit trail — forensic log of thoughts, tool calls, observations (file or on-screen)

Prove it: ask for portfolio risk metrics, ask it to replace one name with another from the universe, then ask it to analyze a ticker with thinking visible in the chat.

Sample portfolio: portfolio.json — copy it into your project and let the agent read/update it.
