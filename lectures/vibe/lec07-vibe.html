Lecture 7: Web Applications

← Slides All lectures · In-class vibe coding

Scenario

Today you’re building a little Yale SOM chatbot — a React page in the browser talking to a FastAPI backend, with a PydanticAI agent that knows some school facts from a JSON file and can also search the web when the JSON isn’t enough.

Download data.zip and unzip next to your project so you get a data/yale_som.json file with programs, location, and a few FAQs for the agent to read.

Task

Scaffold a React + Vite + TypeScript frontend and a FastAPI backend. The page is a simple chat: you type a question about Yale SOM, hit send, and the answer streams back in the chat window. While the agent works, show a spinner (or “thinking…” line) so you know something is happening. If the agent used the school JSON or web search, show a small note under the reply so you can see which tools fired.

Two processes run at once: Vite for the UI (usually http://127.0.0.1:5173) and Uvicorn for the API (usually http://127.0.0.1:8000). The React app calls your FastAPI /api/chat route; that route calls your agent.

Your agent should have these tools:

  • lookup_som — read data/yale_som.json and return relevant facts
  • web_search — search the public web when the JSON doesn’t cover the question

That creates a frontend/ app and downloads packages into node_modules/. Put the FastAPI shell below in backend/main.py (create the backend/ folder if needed).

backend/main.py 
"""Yale SOM chatbot API desk.

Run from backend/:  uvicorn main:app --reload --port 8000
Open API docs:      http://127.0.0.1:8000/docs
Frontend (Vite):    http://127.0.0.1:5173
"""

from __future__ import annotations

from pathlib import Path

from dotenv import load_dotenv
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field

from agent import run_agent

HERE = Path(__file__).resolve().parent
ROOT = HERE.parent
load_dotenv(ROOT / ".env")
load_dotenv(ROOT.parent / ".env")

app = FastAPI(title="Yale SOM Chat", version="0.1.0")
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


class ChatRequest(BaseModel):
    message: str = Field(min_length=1)


class ChatResponse(BaseModel):
    reply: str
    tools_used: list[str] = Field(default_factory=list)


@app.get("/api/health")
def health():
    return {"ok": True, "school": "Yale SOM"}


@app.post("/api/chat", response_model=ChatResponse)
def chat(body: ChatRequest):
    result = run_agent(body.message)
    return ChatResponse(
        reply=result.get("reply", ""),
        tools_used=list(result.get("tools_used") or []),
    )


if __name__ == "__main__":
    import uvicorn

    uvicorn.run("main:app", host="127.0.0.1", port=8000, reload=False)
