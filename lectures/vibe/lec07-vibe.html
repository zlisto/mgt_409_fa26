Lecture 7: Web Applications

← Slides All lectures · In-class vibe coding

Scenario

Today you’re building a Yale School of Management course explorer — a React site that shows the fall course list in a nice grid, plus a chat agent that can answer questions about those classes. FastAPI on the back, PydanticAI for the brain, and a big JSON pack of real SOM courses (titles, faculty, times, descriptions, and a short faculty bio).

Download data.zip and unzip next to your project so you get data/yale_som_classes.json.

Task

Scaffold a React + Vite + TypeScript frontend and a FastAPI backend. The page should feel like a course catalog: cards or a clean list for courses (number, title, faculty, day, time), maybe a search box that filters what you see. Give it some style as well. Be creative and have fun designing it.

Also put a chat panel on the page (bottom-right drawer or a side column is fine). Ask things like “who teaches MGT 409?”, “how many core courses are there?”, or “what are some good AI courses?” While the agent thinks, show a spinner. Under each reply, list which tools ran.

Give the agent these tools:

  • search_courses — search yale_som_classes.json by title, number, faculty, category, day, etc., and return matching rows
  • web_search — search the public web when the JSON isn’t enough (faculty news, syllabus context, etc.)

Software Details

You will make a frontend and backend folder for this project. Your front end is React + Vite + TypeScript. Your backend is FastAPI (Python).

Copy this into your backend folder as requirements.txt:

That creates a frontend/ app and downloads packages into node_modules/. Put the FastAPI shell below in backend/main.py (create the backend/ folder if needed).

backend/main.py 
"""Yale SOM course explorer API desk.

Run from backend/:  uvicorn main:app --reload --port 8000
Open API docs:      http://127.0.0.1:8000/docs
Frontend (Vite):    http://127.0.0.1:5173
"""

from __future__ import annotations

import json
from pathlib import Path

from dotenv import load_dotenv
from fastapi import FastAPI, Query
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field

from agent import run_agent

HERE = Path(__file__).resolve().parent
ROOT = HERE.parent
DATA_PATH = ROOT / "data" / "yale_som_classes.json"
load_dotenv(ROOT / ".env")
load_dotenv(ROOT.parent / ".env")

app = FastAPI(title="Yale SOM Courses", version="0.1.0")
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


def load_courses() -> list[dict]:
    return json.loads(DATA_PATH.read_text(encoding="utf-8"))


class ChatRequest(BaseModel):
    message: str = Field(min_length=1)


class ChatResponse(BaseModel):
    reply: str
    tools_used: list[str] = Field(default_factory=list)


@app.get("/api/health")
def health():
    return {"ok": True, "courses_file": str(DATA_PATH.name)}


@app.get("/api/courses")
def list_courses(q: str | None = Query(default=None)):
    """Return courses for the React catalog (optional text filter)."""
    courses = load_courses()
    if not q:
        return {"count": len(courses), "courses": courses}
    needle = q.lower().strip()
    matched = [
        c
        for c in courses
        if needle in json.dumps(c, ensure_ascii=False).lower()
    ]
    return {"count": len(matched), "courses": matched}


@app.post("/api/chat", response_model=ChatResponse)
def chat(body: ChatRequest):
    result = run_agent(body.message)
    return ChatResponse(
        reply=result.get("reply", ""),
        tools_used=list(result.get("tools_used") or []),
    )


if __name__ == "__main__":
    import uvicorn

    uvicorn.run("main:app", host="127.0.0.1", port=8000, reload=False)

How the app works (for your AI) 
backend/main.py is already saved in this project. Build the agent and React course-explorer UI around it. Do not rewrite or replace main.py unless I ask.

Stack / keys

- PORTKEY_API_KEY=... in a .env (python-dotenv)
- .env may be in this Lecture 7 folder OR the parent folder (e.g. MGT409/.env). Load both.

- Frontend: React + Vite + TypeScript already scaffolded in frontend/
- Backend: FastAPI + uvicorn + pydantic-ai-slim[openai]

Goal
Yale SOM course explorer: React catalog of courses + chat agent that answers questions using tools over data/yale_som_classes.json (and web search when needed). Make the UI look polished (Yale blue / clean type / nice cards) — not the default Vite starter.

How it runs
1) Backend: from backend/, run  uvicorn main:app --port 8000
2) Frontend: from frontend/, run  npm run dev   → http://127.0.0.1:5173
3) UI: course grid/list from GET /api/courses, optional search box, chat panel with spinner + tools_used under replies
4) CORS is already open so Vite can call http://127.0.0.1:8000
5) Data file: data/yale_som_classes.json (unzipped from the course data.zip)

What main.py expects from agent.py
- run_agent(message: str) -> dict with:
  - reply: str
  - tools_used: list[str]  (e.g. ["search_courses"] or ["search_courses","web_search"])

Tools (implement in tools.py, wire in agent.py)
1) search_courses — search yale_som_classes.json by title, number, faculty, category, day, etc., and return matching rows (cap results, e.g. 15)
2) web_search — search the public web when the JSON isn’t enough (faculty news, syllabus context, etc.)

Agent behavior
- System prompt in prompts/prompt.md: helpful Yale SOM course assistant; use search_courses for questions answerable from the course JSON; use web_search when the JSON isn’t enough; never invent course times or faculty; if unsure, say so
- Only these two tools — do not add filter_courses, count_courses, or other extras unless I ask
- Model gpt-5.6-luna + PORTKEY_API_KEY
- Package: pydantic-ai-slim[openai]

Structured types (models.py)
- AgentResult with fields: reply (str), tools_used (list[str])
