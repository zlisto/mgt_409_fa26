Lecture 3: Tools & Skills

← Slides All lectures · In-class vibe coding

The Scenario

Build a stock research chatbot. People should be able to open a web app, chat with the bot (“What’s Apple’s recent volatility?” / “Any news on Microsoft?”), and get answers grounded in live market data and web search results.

The Task

1. Create an AGENTS.md with basic rules you’ll reuse all semester: which AI model to use, how to handle API keys, and the app look you want (for example a modern black-and-pink style).

2. Write a chatbot skill you’ll reuse for chat apps all semester. Cover the mechanics and look of the chat UI: message history, a text box to type in, Enter (or a Send button) to submit, how replies appear, and the styling you prefer.

3. Write a finance tools skill for today’s build. Spell out:

  • Live market data from Yahoo Finance (never invent prices)
  • Custom tools that compute financial metrics (price, momentum, volatility, Sharpe, and similar)
  • A web search tool for recent financial news

4. Use both skills to build a Dash stock research chat app: the chatbot skill for the UI, the finance skill for the tools. The model should call those tools, return live answers, and show you when a tool ran.
