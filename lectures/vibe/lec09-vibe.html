Lecture 9: MCP Servers

← Slides All lectures · 40 minutes in class

In-class goal: Leave with a tiny MCP-style server that implements list_tools() and call_tool() over local JSON — the same contract Homework 5 uses for Peabody, without completing HW5. If time allows, one Python script that imports those two verbs. Do not build the Lecture 10 orchestrator.

Do not download the Peabody zip for this session. If your vibe coder starts writing get_exhibit_info, you accidentally started homework. Stop. Come back to scoops.

40-minute clock

  1. 0–8 — Toy JSON + manifest (two tools, no LLM)
  2. 8–22 — list_tools + call_tool + honest error
  3. 22–30 — Catalog + one real sample per tool
  4. 30–37 — Tiny asker that imports the plug (not an orchestrator)
  5. 37–40 — AI_prompts.md

Step 1 Toy shop JSON 0–8 min

Make two fake desks so the server has something honest to read. No OpenAI key yet.

Create lec09_mcp/ with tools/hours.json and tools/flavors.json for a fictional New Haven shop called Elm City Scoops. hours.json: weekly hours (closed Monday), address. flavors.json: at least 4 scoops with name, has_nuts, seasonal. Add mcp_manifest.json with two tools: get_hours (optional day) and get_flavors (optional query). README says this is a lecture toy, not Homework 5.
Check: Three JSON files exist; manifest tool names match the two files.

Step 2 list_tools + call_tool 8–22 min

USB-C is two verbs. Implement both. Unknown names must fail loudly. This is the whole lecture in code.

Create mcp_server.py that loads mcp_manifest.json and the files under tools/. Implement list_tools() returning name, description, input_schema for each tool. Implement call_tool(name, arguments) that reads the matching JSON (filter by day or query if provided). Unknown tool names return an error object {error, tool} — never invent flavors. CLI: python mcp_server.py --data-dir lec09_mcp --out-dir output. No OpenAI key needed for this step.
Check: Calling a fake tool name returns an error object. Calling get_hours returns hours from the file, not from memory.

Step 3 Write the catalog and samples 22–30 min

Prove the plug works before any LLM shows up. Same shape as HW5 Problem 3.

When mcp_server.py runs, write output/tool_catalog.json from list_tools(). Also write output/tool_sample_hours.json and output/tool_sample_flavors.json, each with keys tool, arguments, result from a real call_tool. Include one extra output/tool_sample_unknown.json showing the error path.
Check: Four JSON files in output/. Catalog has exactly two tools. Unknown sample has an error key.

Step 4 Tiny asker that uses the plug 30–37 min

One LLM call path is enough. Import the two verbs. Do not build a multi-tool loop, traces, or “refuse when tools disagree” — that is Lecture 10 / HW5 P4–P5.

Create ask_scoops.py that loads OPENAI_API_KEY from .env, imports list_tools and call_tool from mcp_server.py (do not copy the tool bodies), and answers one user question by: (1) listing tools, (2) calling one or two tools, (3) writing output/scoops_answer.json with query, answer, tool_trace. Prompt file prompts/scoops.md: only use tool results; if tools don't cover it, say you don't know. Example query: "Are you open Tuesday, and do you have a nut-free scoop?"
Check: scoops_answer.json has a tool_trace with real tool names from the manifest. Answer mentions a fact that appears in the JSON files. If the API call is slow, skip to Step 5 and finish later.

Step 5 AI_prompts.md 37–40 min

Course habit: log what you actually typed.

Add a Lecture 9 section to AI_prompts.md with the prompts above in your own words, plus one sentence on what broke after the first try if anything did.
Check: AI_prompts.md has Lecture 9 with at least four prompt summaries, not a paste of this page.

Stretch FastMCP or a third tool if you finish

Optional. Homework 5 still accepts a local dispatcher. Do not start Peabody.

Either (A) add get_allergen_policy as a third tool with tools/allergens.json and update the manifest, or (B) wrap the same list_tools/call_tool contract with FastMCP and note the extra dependency in README. Do not start the Peabody assignment in this folder.
Check: Third tool or FastMCP path still returns errors for unknown names.

Stretch: Draw a 4-box HTML diagram (user → ask_scoops.py → mcp_server.py → JSON files) saved as output/pipeline.html. Preview of HW5 Problem 7, not a substitute.
