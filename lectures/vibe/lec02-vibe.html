Lecture 2: Structured Data from Free Text

Step 1 Scaffold (0–5 min)

Same hygiene as Lecture 1. The homework zip layout comes later; today is one folder.

Create a folder lec02/ with:
- extract_receipt.py (empty for now)
- prompts/receipt_extract.md (placeholder)
- prompts/reconcile.md (placeholder)
- sample_data/receipt_class.txt
- output/
- requirements.txt (openai, python-dotenv)
- .env.example with OPENAI_API_KEY=
- .gitignore ignoring .env, __pycache__, and output/*.json
- README with venv + pip + copy .env.example
Do not put a real API key in any file.
Check: Folder exists; .gitignore lists .env; no key in git-tracked files.

Step 2 Write a messy receipt (5–10 min)

Do not copy Homework 1 PDFs. Invent a classroom receipt so the schema is the point.

In sample_data/receipt_class.txt write a short fake bike-shop receipt as plain text. Include: store name, a date in January 2026, two line items, a total in dollars, and a note that tax is not shown as its own line. Leave the payment method blank so one field is actually missing.
Check: File is text, not a PDF. You can see a total and at least one missing fact.

Step 3 The prompt is the contract (10–16 min)

This file is what extract_receipt.py will load — the homework’s prompts/*.md pattern. It is not AI_prompts.md.

Replace prompts/receipt_extract.md with instructions for an accounts-payable clerk.

Extract JSON with keys:
source_file (string), vendor (string), date (YYYY-MM-DD), description (string), amount_usd (number), category (one of parts, labor, tools, other), payment_method (string or null), fields_not_found (array of strings).

Rules:
- Return JSON only. No markdown fences.
- If a field is not in the text, use null and add the key name to fields_not_found.
- Never invent amounts or vendors.
- If category is unclear, use other and list category in fields_not_found.
Check: Prompt names every field, states types, and has “do not invent” language.

Step 4 One script, one LLM call, one JSON file (16–25 min)

Homework 1 will loop over many PDFs. Today: one text file. Stay on the course model (often a mini-class via Portkey).

Write extract_receipt.py that:
1. Takes --text-file and --out (default output/receipt.json)
2. Loads prompts/receipt_extract.md as the system prompt
3. Sends the file contents plus the filename as the user message
4. Calls the OpenAI API with response_format json_object (model: same mini-class as Lecture 1 unless the course instructions say otherwise)
5. Parses JSON
6. Writes the object to --out
7. Prints token usage
Use python-dotenv for OPENAI_API_KEY. Clear error if the key is missing.
Check: python extract_receipt.py --text-file sample_data/receipt_class.txt writes valid JSON with the keys from Step 3.

Step 5 Validator before you trust it (25–32 min)

Structured output can still be a fluent lie. Catch it in code.

Add validate_receipt(data) and call it before writing the file.

Checks:
- required keys present
- amount_usd is a number >= 0, or null
- if amount_usd is null, fields_not_found includes "amount_usd"
- date matches YYYY-MM-DD when not null
- category is in {parts, labor, tools, other}
On failure raise ValueError with a readable message. Do not silently coerce bad amounts.
Check: Temporarily break a field in a test dict; the script refuses to write.

Step 6 Mini recon + Python total (32–37 min)

Homework 1: LLM books once (P5), Python adds (P7). Do not sum the receipt and the card. Invent a second source — do not use the HW1 zip.

1. Write sample_data/card_line.json by hand: same amount_usd as your receipt, vendor mangled (e.g. PARKTOOL), source_file "card_jan.txt", category other.
2. Replace prompts/reconcile.md: given two JSON objects, decide if they are the same purchase. Return JSON only: booked_amount_usd (number), same_purchase (boolean), resolution (one sentence), fields_not_found (array). Do not average. If same, book once.
3. Write reconcile_class.py: load output/receipt.json and sample_data/card_line.json, call the LLM with reconcile.md, write output/recon.json, print the JSON.
4. Write pnl_class.py: load output/recon.json and print booked_amount_usd. No LLM. Do not add receipt amount + card amount.
Check: recon.json has one booked amount. pnl_class.py prints that number, not a double count.

Check: File exists; bullets are paraphrases, not a copy-paste of this vibe page.
