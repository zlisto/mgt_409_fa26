Lecture 2: Structured Data from Free Text

← Slides All lectures · In-class vibe coding

The Scenario

You are an asset manager who just inherited a portfolio of commercial real estate properties. You have a folder of raw lease agreements in PDF format, and you need a fast, automated way to see what you actually own, where it is, and when tenants might leave.

The Task

Use an AI model and Python to extract key data from the lease PDFs, save it as structured JSON, and build an interactive Plotly Dash web dashboard to visualize the portfolio — including plotting the properties on a map.

The lease PDFs for this session are available at sample_leases.zip.
