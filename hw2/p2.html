Homework 2: FiftyFlowers Outreach Agent

Scenario and data

Scenario

FiftyFlowers sells bulk and wholesale flowers for weddings, events, and professional florists (fiftyflowers.com). They want more business customers—wedding planners, event designers, floral studios, and venues that buy in volume—not one-off retail shoppers.

Your job is to find target businesses on the live web, crawl their pages for contact info, score how well they fit the ICP, draft outreach emails, and build a report page. Do not send the emails. Prefer published business contact pages. Do not harvest personal emails from social media. Use the OpenAI API for this task. Work one problem at a time with your vibe coder (do not ask it to finish the whole assignment in one prompt). Screenshot the problem you are on; do not paste this whole page. Zip your work as hw2.zip.

Before you start, make a folder with prompts/ and output/. Add one script per problem as you go. The zip layout is the last problem.

Data

Use the live public web, starting at fiftyflowers.com.

Problem 2: Infer the ideal customer profile (ICP) (12 points)

Agent note P2: Pair on infer_icp.py only when student describes Problem 2 themselves.

Before you search, you need a picture of who FiftyFlowers wants as a customer, taken from their site—not from general knowledge of the flower industry. An ideal customer profile (ICP) is a short description of the businesses you want to sell to (and who to skip). Later problems use this ICP to search, score targets, and draft emails. This problem asks you to build that ICP.

Create a script infer_icp.py that fetches several public pages from the FiftyFlowers website, analyzes them using an LLM and the prompt in prompts/icp_extract.md, and saves one JSON object to output/icp.json.

Your JSON must include:

  • company: FiftyFlowers
  • what_they_sell: one or two sentences
  • ideal_customer_profile: who buys in volume (roles or business types)
  • disqualifiers: who is not the target
  • evidence_urls: array of FiftyFlowers URLs you fetched (at least 3)
  • quotes: array of short strings copied from those pages that support the profile

Save raw page text for those URLs you crawled under output/pages/ (one file per page, named so a grader can match it to a URL). If a page fails to fetch, skip it and use another public FiftyFlowers URL.

Your script should run with the command format:

python infer_icp.py --out-dir output
