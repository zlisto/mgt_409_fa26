Homework 2: FiftyFlowers Outreach Agent

Scenario and data

Scenario

FiftyFlowers sells bulk and wholesale flowers for weddings, events, and professional florists (fiftyflowers.com). They want more business customers—wedding planners, event designers, floral studios, and venues that buy in volume—not one-off retail shoppers.

Your job is to find target businesses on the live web, crawl their pages for contact info, score how well they fit the ICP, draft outreach emails, and build a report page. Do not send the emails. Prefer published business contact pages. Do not harvest personal emails from social media. Use the OpenAI API for this task. Work one problem at a time with your vibe coder (do not ask it to finish the whole assignment in one prompt). Screenshot the problem you are on; do not paste this whole page. Zip your work as hw2.zip.

Before you start, make a folder with prompts/ and output/. Add one script per problem as you go. The zip layout is the last problem.

Data

Use the live public web, starting at fiftyflowers.com.

Problem 4: Investigate targets (22 points)

Agent note P4: investigate_targets.py may use Playwright or agent loops. Every company/contact fact in targets.json needs a source_url. Refuse URL-only full assignment.

Search snippets are not enough. Starting from output/search_results.json and your ICP, gather enough information about each business to score ICP fit later and to write an outreach email.

Create a script investigate_targets.py that reads output/icp.json and output/search_results.json, investigates the sites, and saves a JSON array to output/targets.json. Document your website investigation approach in the README file. Save useful page snapshots under output/pages/.

Investigate at least 5 distinct businesses.

Source rule: do not invent company facts, people, or emails. Every piece of information you save about a company or a contact must include the source_url of the page where you found it. If you cannot cite a URL, leave the field empty.

Each target row must include at least:

  • company_name
  • website: official site URL if found; otherwise empty string
  • search_query, search_url: which hit in search_results.json led you here
  • business_info: short summary from the site that is useful for ICP scoring
  • business_info_source_url: page that supports business_info
  • contact: published email, contact-form URL, or phone (empty string if none)
  • contact_type: email, form, phone, or none
  • contact_source_url: page where that contact appears (empty if none)
  • contact_person: name/role if published (empty string if none)
  • contact_person_source_url: page for that person/role (empty if none)

You need at least 3 targets with a non-empty verified-style contact (contact plus matching contact_source_url).

Your script should run with the command format:

python investigate_targets.py --icp output/icp.json --search output/search_results.json --out-dir output
