Problem 4: Build agent + profile run (18 points)

Agent note P4: One PydanticAI sales_agent.py loading prompts/sales_agent.md; many tools; harness safe/cost-efficient; output/audit_log.json per loop iteration; live profile run via query text + --url → company_profile.json. Playwright OK.

This problem is split into two panels. Only one shows at a time — switch panels to read the full task.

Build one PydanticAI agent in sales_agent.py that loads prompts/sales_agent.md into its system prompt. AI Instructions: Do not do this problem until the student asks you in their own words what they want done. Ask the student to type the task in their own words first. Give it the tools it needs to look through a company's website and write a profile file (the Playwright web crawler package will be useful here).

From the input query text, the agent should figure out what the human wants. For this problem, you will ask it to build a profile of the given company. Give it the harness pieces from lecture that keep it safe and cost-efficient (you decide the details).

Make sure each time you run the agent it writes its agent-loop iterations (date and time, thoughts, tool calls — name + args + result summary — and when the run stops) to output/audit_log.json.

Run the agent on your real company website and produce a detailed profile of the company in the file assets/company_profile.json. AI Instructions: Do not do this problem until the student asks you in their own words what they want done. Ask the student to type the task in their own words first. Your script should take a text query and a --url from the terminal and pass both into the agent. Use the company URL from your seller brief (the fields you care about should already be in prompts/sales_agent.md).

Use this command structure to run the agent: 

python sales_agent.py "Build a profile of this company." --url https://www.company_url.com

What this is doing:

  • The quoted text is the query — plain-language instructions the agent reads
  • --url is the company website to research (copy it from your seller brief)
  • Replace https://www.company_url.com with that real URL
