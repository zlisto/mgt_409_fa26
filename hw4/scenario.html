Scenario and data

Scenario

Campus Customs needs a real customer website with a helpful chatbot. You will build a React + Vite TypeScript front end and a Python FastAPI backend whose brain is a PydanticAI agent. Shoppers should be able to browse products, create an account, chat about merch, see matching items appear on the page, and get honest answers about price and stock from a local database.

You are given campus_customs.db with tables for the product catalogue, inventory by size, and users (with hashed passwords). Product image file paths are in the catalogue table. Research yalebulldogblue.com to learn the style of Campus Customs page and information for your agent prompt.

Use your PORTKEY_API_KEY, or whatever API key you have for your agent's AI calls. If using OpenAI through Portkey use any models in the 5.6 or 6 series. You may want a smarter model for harder agent steps.

Work one problem at a time with your vibe coder. Type each problem in your own words. Do not paste the page URL, and do not screenshot the problems to finish everything. In the end you will push your project to a public GitHub repo and submit the repo URL on Canvas (the last problem shows the file tree). Do not commit the database or product images.

Data

Download data.zip (when posted). Unzip so you have:

  • data/campus_customs.db — SQLite database with tables catalogue, inventory, and users (one test user is already there)
  • data/products/ — product images; paths match the catalogue table
