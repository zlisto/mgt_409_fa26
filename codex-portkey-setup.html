Connect Codex to the Yale Portkey API

Install the Codex extension, open the settings file from the Codex chat, paste the class block, and put your Yale Portkey key in that file. Then fully quit VS Code and reopen it.

What You Are Doing

Tell Codex to send class work through Yale's Portkey gateway instead of a personal OpenAI login. Put your Portkey key in Codex's settings file. The class default is gpt-5.6-luna, a lower-cost model so Yale's course allocation lasts the term. Do not share your key, post it online, put this file in a homework zip, or include it in screenshots.

10 minutes Works on Mac and Windows Open the file from the Codex chat Restart VS Code at the end

How to Open config.toml

Do not hunt for this file in File Explorer or Finder. Open it from the Codex chat on the right side of VS Code.

Codex chat (right side)→Gear (top right of that panel)→Configuration→Open config.toml
  • Click the Codex tab in the chat panel on the right. If you do not see it, click the Codex icon in the left icon strip.
  • In the top-right of that Codex panel, click the small gear. A Codex Settings tab opens.
  • On the left of that settings tab, click Configuration.
  • Click the Open config.toml button.
Your key goes in this file. Keep the double quotes around it. You do not need PowerShell, Terminal, or an environment variable.

Before You Start

  • Have your Yale Portkey API key ready.
  • Pick the Windows or Mac tab below only to install VS Code.
  • After Codex is installed, use the click path above. It is the same on both computers.

Windows Setup

  1. Install VS Code

    Go to code.visualstudio.com/download, choose the Windows download, run the installer, and open VS Code.

  2. Install the Codex extension

    Click the Extensions icon on the left, or press Ctrl+Shift+X. Search for Codex, choose the OpenAI Codex extension, and click Install.

  3. Open config.toml from the Codex chat

    Open the Codex chat on the right side. Click the gear in the top-right of that panel, click Configuration, then click Open config.toml.

    Codex chat→Gear→Configuration→Open config.toml
  4. Paste this and put your key in it

    If the file is blank, paste the whole block. Replace paste-your-portkey-key-here with your real Portkey key. Keep the double quotes. Save with Ctrl+S.

    config.toml
    model = "gpt-5.6-luna"
model_provider = "portkey"
model_reasoning_effort = "low"

[model_providers.portkey]
name = "Portkey"
base_url = "https://api.portkey.ai/v1"
experimental_bearer_token = "paste-your-portkey-key-here"
  5. Fully quit VS Code and reopen it

    Do not just close the tab. Quit VS Code, then open it again so Codex reloads the file.

Windows Checks

Use these if something does not work.

Success looks like: Codex starts a chat without asking you to log into ChatGPT, and the model shows as Luna.
Cannot find the gear? It is in the Codex chat panel on the right, not in VS Code's File menu. If the right panel is missing, click the Codex icon in the left icon strip.
Left the placeholder in? Replace paste-your-portkey-key-here and keep the double quotes.

TA Troubleshooting Script

  • Confirm VS Code is installed and the OpenAI Codex extension is installed and enabled.
  • Open the file from the Codex chat on the right: gear (top-right of that panel) → Configuration → Open config.toml. The VS Code File menu is the wrong place.
  • If the right-side Codex panel is missing, click the Codex icon in the left icon strip.
  • Confirm the key is a Portkey key, not a personal OpenAI key, and that it replaced paste-your-portkey-key-here.
  • Confirm the quotes around the key are straight quotes, not curly quotes.
  • Confirm config.toml contains model_provider = "portkey" and experimental_bearer_token = "...".
  • Fully quit VS Code after the file is saved, then reopen it.

Undo Yale Portkey Setup

Only use this if your instructor or TA tells you to go back to a personal OpenAI setup. Remove the Portkey block, including the experimental_bearer_token line.

config.toml
model = "gpt-5.6"
model_provider = "openai"
Keep API keys private. When in doubt, ask a TA before changing the config file.
